# Scobie Construction Co.

**Decks, Debts & Small Talk** — a cosy, playable garden construction and project-management game.

The complete game, source, controls and verification notes are in [decks-debts/README.md](decks-debts/README.md).

```sh
cd decks-debts
npm run dev
```

Open http://localhost:5173. No dependency installation is required.
